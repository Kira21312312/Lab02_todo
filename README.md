# Задачник
Приложение создано что бы добавлять и следить за своими задачами можно отслеживать какие сделал или какие еще предстоит сделать.

Автор: Кирилл ИСП-243

## Запуск
1. Клонировать репозиторий: `git clone <url>`
2. Перейти в папку: `cd lab2_todo`
3. Установить зависимости: `dart pub get`
4. Запустить: `dart run`

## Чему научился:
1. Назначение и применение конструктора класса
2. Преопределение метода
3. Понятие статического поля
4. Разница меж полем класса и локальной пременой

## Ответы на вопросы:
1. Поля класс внутри класса а локальная переменная в функции или методе.
2. Конструктор - метод класса для создания обьектов класса
3. Сообщение о переопределении метода
4. Обычное для обьекта класса а статистическое для самого класса, одна.
5. Означает что оно приватно для файла.
